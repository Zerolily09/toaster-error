The error message a kitchen toaster shows its owner when something goes wrong: one line, at most 120 characters, written to read like a real message on a real appliance.

Built by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

It prints the entry's one line, and nothing else. No dependencies, no network,
no state: the same line every run.
